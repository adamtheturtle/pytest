Improved test collection performance for large suites.

This includes caching path-sensitive hook proxies (invalidated when new
conftests load), skipping fixture reordering when only function-scoped
parametrization is used, reusing function-definition nodes for
non-parametrized tests, deferring ``TopRequest`` creation until setup,
faster fixture argument discovery and first-time parametrization, and
fewer filesystem stats while resolving conftest directories.
